Embark on this challenging yet rewarding journey to master humanoid robotics and AI! The assessments are designed to solidify your learning, encourage practical application of the concepts, and prepare you for real-world robotic challenges. Embrace each assessment as an opportunity to innovate, experiment, and showcase your growing expertise. We are excited to see what you create!

Course Assessments

Assessment 1: ROS 2 Package Development Project​

  • Description: Design, implement, and test a ROS 2 package that performs a specific robotic task (e.g., sensor data acquisition, basic control, or inter-node communication). This project will assess your understanding of ROS 2 architecture, nodes, topics, services, and package management.
  • Deliverables: Functional ROS 2 package, README with setup instructions, and a short demonstration video.

Assessment 2: Gazebo Simulation Implementation​

  • Description: Develop a detailed robot model (URDF/SDF) and a corresponding Gazebo world to simulate a specific robotic scenario. You will implement sensor simulation and basic interaction logic to test a particular robotic behavior or algorithm.
  • Deliverables: Robot model files (URDF/SDF), Gazebo world file, simulation demonstration, and a report detailing your implementation choices.

Assessment 3: Isaac-based Perception Pipeline​

  • Description: Build an AI-powered perception pipeline using NVIDIA Isaac Sim. This will involve simulating sensors, generating synthetic data, and implementing an AI model for tasks such as object detection or scene segmentation relevant to robotics.
  • Deliverables: Isaac Sim environment setup, perception pipeline code, trained AI model (or script for training), demonstration of pipeline performance, and a technical report.

Assessment 4: Capstone: Simulated Humanoid Robot with Conversational AI​

  • Description: The capstone project involves integrating multiple learned skills. You will develop a simulated humanoid robot (potentially using ROS 2 and Gazebo/Isaac Sim) capable of natural human-robot interaction. This includes implementing conversational AI (potentially with GPT integration), multimodal input understanding (speech, gesture), and task execution based on dialogue.
  • Deliverables: A fully functional simulation of a humanoid robot performing a task via conversational commands, source code, a detailed project report, and a comprehensive demonstration video.
